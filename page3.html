How WannaCry Works

The WannaCry ransomware spread using the EternalBlue exploit, developed by the National Security Agency (NSA), then stolen. It targeted the Server Message Block vulnerability in Microsoft Windows operating systems running outdated versions, including Windows XP, Windows 8, and Windows Server 2003, to install a backdoor, making it easier for hackers to access the system. The malware then encrypted the data to hold it for ransom.

The program demanded payment within three days, threatening to double the ransom amount afterward. If the victim did not pay within a week, the data would be deleted.
