WannaCry Today

The WannaCry ransomware itself is less active today, but it remains a latent threat for unprotected systems, and other ransomware variants inspired by WannaCry continue to circulate.

  • The propagation mechanism (exploiting EternalBlue) has been reused in other major cyberattacks (e.g., NotPetya).

To protect against cyberattacks such as WannaCry, it is recommended:

  • Regularly install software patches, especially those released by Microsoft to address vulnerabilities.
  • Regularly back up data on offline storage media.
  • Keep protection tools such as antivirus and anti-malware software up to date.
  • Train users to recognize phishing emails and other cyber threats.
  • Install all available security patches for your operating system and key applications.
  • Use an up-to-date operating system that includes the latest security features.
